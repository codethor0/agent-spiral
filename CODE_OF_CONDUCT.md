# Code of Conduct

## Our standard

This project exists to explain how systems fail. People here are expected to
be precise, honest, and direct:

- Be respectful and professional in all interactions.
- Critique code and ideas, never people.
- No harassment, personal attacks, or discrimination of any kind. This
  includes slurs, unwanted advances, and sustained mockery.
- Accept correction gracefully. If you are wrong, say so and move on.
- Assume good faith in reviews; ask before assigning bad intent.

## Scope

This standard applies to the repository, its issues and pull requests, and
any project space where people represent it (chat, social media, events).

## Reporting

Report violations privately through GitHub Security Advisories (the
repository Security tab, "Report a vulnerability") or by direct message to
the maintainer. Reports are handled confidentially.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that violate this standard, and may ban contributors
temporarily or permanently for repeated or severe violations.
